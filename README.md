# 작은 숲 — 3D 블록 샌드박스

브라우저에서 걷고, 블록을 부수고, 원하는 풍경을 만드는 싱글플레이 게임입니다. HTML, CSS, JavaScript와 Three.js로 구현했습니다. 게임 서버, 데이터베이스, 계정, 외부 API는 사용하지 않습니다.

## 실행

Node.js 22.12 이상과 npm을 준비한 뒤 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 주소를 데스크톱 Chrome, Edge 또는 Firefox에서 여세요. 기본 주소는 `http://localhost:5173`입니다. **내 세계로 들어가기**를 누르면 마우스가 게임 안에 잠깁니다. 브라우저가 허용을 요청하면 마우스 잠금을 허용하세요. HTML 파일을 직접 더블클릭하는 `file://` 실행은 지원하지 않습니다.

Vite는 파일을 제공하는 개발 도구입니다. 게임 자체에는 서버 연결이 없습니다. 최초 의존성 설치 후에는 폰트·이미지·Three.js를 CDN에서 가져오지 않습니다. 로컬 서버가 켜져 있으면 인터넷 없이 플레이할 수 있습니다.

클라우드 환경에서 기본 npm 캐시 경로에 쓸 수 없다면 `npm ci --cache /tmp/codex-npm-cache`를 사용하세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 앞 / 왼쪽 / 뒤 / 오른쪽 이동 |
| 마우스 이동 | 시점 회전 |
| Space | 지면에서 점프 |
| 왼쪽 클릭 | 조준한 블록 파괴 |
| 오른쪽 클릭 | 조준한 면에 선택한 블록 설치 |
| 1 / 2 / 3 / 4 / 5 | 풀 / 흙 / 돌 / 나무 / 모래 선택 |
| Esc | 일시정지, 마우스 잠금 해제 |
| 계속 탐험하기 | 현재 월드에서 이어 하기 |
| 처음부터 다시 만들기 | 편집한 월드를 초기화하고 시작 위치로 이동 |

조작은 게임 실행 중에만 적용됩니다. 블록은 6칸 안에서 편집할 수 있고, 플레이어 몸과 겹치는 위치에는 설치할 수 없습니다. 가장 아래의 기반암은 파괴할 수 없습니다. 섬 밖으로 떨어지면 시작 위치로 돌아옵니다. 창을 떠나거나 다른 탭으로 전환하면 일시정지합니다.

월드 변경은 현재 탭의 메모리에만 유지됩니다. **새로고침, 탭 종료, 다시 시작 시 초기화**되며 자동 저장 기능은 없습니다. 터치 조작과 모바일 플레이는 지원하지 않습니다.

## 구현 구조

- `index.html`, `style.css`: 시작·일시정지 메뉴, 조준점, 선택바, 반응형 화면.
- `src/game.js`: Three.js 렌더링, 마우스 잠금, 키보드 입력과 블록 편집.
- `src/world.js`: 32×32 지형 생성, 블록 저장과 광선 선택.
- `src/physics.js`: 중력, 점프, 플레이어와 지형의 충돌.
- `test/physics.test.js`: 월드와 물리의 자동 테스트.

화면에 노출된 블록만 종류별 `InstancedMesh`로 묶어 그립니다. 블록 선택은 메시 전체를 검색하지 않고 광선이 지나가는 격자를 따라갑니다. 충돌은 1/120초 간격으로 계산하며 작은 이동 단위로 나누어 바닥 관통을 방지합니다. 이번 버전은 작은 월드에 맞춰 편집할 때 노출 블록을 다시 구성합니다. 큰 월드로 확장할 때는 청크별 갱신과 면 병합이 필요합니다.

이동 속도·점프·중력은 `PLAYER`, 월드 범위·편집 거리는 `WORLD` 상수에서 조절할 수 있습니다.

## 검증 및 배포용 빌드

```sh
npm test
npm run build
npm run preview
```

`npm test`는 지형 생성, 고속 낙하, 점프와 공중 점프 제한, 벽·천장 충돌, 대각선 이동 속도, 광선 거리와 음수 좌표, 플레이어 겹침, 월드 초기화를 검증합니다. `npm run build`는 `dist/`에 정적 파일을 생성하고 `npm run preview`는 해당 빌드를 로컬에서 확인합니다. 배포는 자동으로 수행하지 않습니다.

WebGL을 지원하고 하드웨어 가속이 켜진 데스크톱 브라우저를 권장합니다. WebGL 초기화에 실패하면 안내 메시지를 표시합니다. 게임 화면에서 시작 → 이동·점프 → 블록 파괴·설치 → Esc → 계속하기 → 다시 시작 순서로 수동 확인할 수 있습니다.

### 이번 버전에서 확인한 결과

- Node.js 자동 테스트 8개 통과, Vite 배포용 빌드 성공.
- 의존성 검사에서 발견된 문제를 Vite 7.3.7과 esbuild 0.28.2로 갱신해 해결했으며, `npm audit` 결과 알려진 취약점 0건.
- Chromium에서 WebGL 실행, 마우스 잠금, 이동·점프, 숫자키 선택, 클릭 파괴·설치, 일시정지·계속하기·재시작 확인. 페이지 실행 오류 없음.
- 390px 화면에서 가로 넘침 없음. 터치 플레이 검증을 의미하지는 않습니다.
- 클라우드의 소프트웨어 WebGL로 기능을 검증했으며, 실제 GPU 성능과 Firefox·Safari는 직접 검증하지 않았습니다.
